# Games

Each game gets its own folder in here, e.g.:

    games/
      my-game/
        index.html
        game.js
        cover.svg   (16:10 cover art for the library card, optional)
        assets/

Link ../../css/game.css from the game's index.html to get the shared Playforge
frame (copy race-car/index.html as a starting point).

To show it on the site, add an entry to the `GAMES` list in ../js/main.js.
